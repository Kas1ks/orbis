# Orbis

Одна браузерная вкладка ведущего для уже собранной кампании. Страница не ставится, не просит учётную запись и во время партии никуда не обращается. Игроки сидят за столом; в Orbis смотрит только ведущий.

Сюжет пишется снаружи и приносится файлом или вставкой в формате `orbis/1`. Внутри нет чата и нет генерации. Партия читает только отмеченную ревизию: фазы, выборы, флаги и уже лежащий следующий сценарий.

## Как открыть

Из папки репозитория:

```bash
python3 -m http.server 8000
```

Затем в браузере открыть http://127.0.0.1:8000/

Тот же `index.html` открывается и файлом с диска: скрипты лежат рядом, пример кампании вшит в страницу.

Две двери:

- **Приём данных** — файл YAML/JSON или вставка, проверка, правка уже лежащих фраз, связей и флагов, отметка ревизии.
- **Партия** — имена сыщиков и вечер по готовой ревизии.

Из партии приём не открывается, пока сессия не закончена.

В приёме есть пример **«Соль на пороге»**: два авторских сценария. Флаг `salt_on_the_threshold` переходит из первой ночи во вторую. Чужих текстов, карт и файлов сценариев там нет.

Проверка движка:

```bash
node --test test/engine.test.js
```

## Вечер

Слева — что зачитать и что положить или убрать со стола. Справа — пометка ведущему, скрытые комнаты без текста их событий, флаги, часы и отпечаток ревизии. Туда же кнопки: открытие, три фазы круга, жетон, существо снято, именной такт, выбор, отмена последнего шага, пауза.

Отмена откатывает снимок состояния. Нового текста вечером взять неоткуда.

Закрытая вкладка не обязана помнить вечер. **Скачать снимок вечера** пишет файл `orbis-session/1`. Его открывают на двери партии. Ревизия скачивается файлом `orbis-revision/1`; отпечаток в партии — короткий след содержимого, не номер, который вечер мог бы переписать.

## Формат orbis/1

Ключи английские, текст — на языке стола. Идентификаторы: латиница и `_`. Ссылки только внутрь того же пакета. Неизвестный ключ — ошибка. Команды только из списка: `reveal`, `hide`, `set_flag`, `clear_flag`, `add_clock`, `go`, `end`.

```yaml
format: orbis/1
campaign:
  id: salt_threshold
  title: Соль на пороге
  pitch: только ведущему
  flags: [salt_on_the_threshold]
  scenarios: [dry_pier, net_loft]
  start: dry_pier
scenarios:
  - id: dry_pier
    title: Ночь сухой пристани
    spare: false                 # true, если вход запасной и сам из start не достижим
    investigators: { min: 1, max: 4 }
    setup:
      read_aloud: текст для стола
      host_note: пометка ведущему
      present: [customs_hall]
    clock: { name: Мокрый час, start: 0, limit: 4 }
    components:
      - { id: customs_hall, kind: room, label: Сени таможни, host_note: "", at: null }
    events:
      - id: opening_bell
        when: { on: phase, phase: opening }   # session_start | phase | marker_used | creature_down | clock_at | flag_is | host_calls
        read_aloud: ...
        host_note: ...
        choices:
          - label: Стол готов
            effects: []          # либо effects на событии, если выбора нет
    endings:
      - id: pier_held
        kind: success            # success | failure | other
        when: { on: event, event: opening_bell }
        read_aloud: ...
        host_note: ...
        set_flags: [salt_on_the_threshold]
        next: net_loft           # или stop
```

Повод `when` — ровно один. К нему добавляется поле: `phase` (`opening`, `actions_done`, `pressure`, `creatures`), `component`, `value`, `flag`, либо для такта `call` и `label`. У финала повод `flag_is`, `clock_at` или `event`.

Пустой `read_aloud` допустим только у события с командами и без выбора: ведущий его не читает, шаг проходит сам. У каждого сценария есть успех и провал. Сценарий, недостижимый из `start`, помечается `spare: true`. Флаг из тетради кто-нибудь ставит. Цикл без пути к `end` — ошибка.

В тексте только подстановки `{investigators}`, `{names}`, `{clock}`, `{clock_name}` и `{component:id}` уже открытого компонента. Адресов сети и ключа модели в пакете нет.

Внутреннее дерево одно: страница принимает YAML и JSON. Ревизия и снимок пишутся JSON.
